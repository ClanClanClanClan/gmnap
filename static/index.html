About MathLineage

MathLineage is the Global Mathematician Name Authority Pipeline (GMNAP) v7 — an automated system for creating and maintaining authoritative records for the world's mathematicians.

Why?

The Mathematics Genealogy Project has served the community for decades, but it relies on manual volunteer updates, contains errors, and covers only PhD relationships. MathLineage automates this with data from 9 academic authority sources, linguistic processing for 37 world regions, and graph-based lineage tracking.

How it works

  1. Ingest — Unicode normalisation (NFC/NFKD), script detection
  2. Region Detection — FastText language ID + script analysis + diaspora overlay
  3. Linguistic Processing — 34 rules for name ordering, particles, patronymics, transliteration
  4. Authority Enrichment — Cross-reference with OpenAlex, Crossref, ORCID, zbMATH, Wikidata, HAL, GND
  5. Collision Detection — DuckDB-based duplicate analysis with deterministic GlobalID assignment
  6. Graph Consistency — Bayesian coherence scoring against Memgraph genealogy database
  7. Schema Validation — JSON Schema v2.0 with configurable strictness
  8. Quality Gates — 8 automated checks before any record is published

Technology

Python 3.12, FastAPI, Memgraph, DuckDB, FastText, Docker. Processes 2,000 entries/sec offline, handles 1M+ records in under 10 minutes.

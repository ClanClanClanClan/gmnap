## How to re-include one

1. Inspect the test file for the symbol it expects.
2. Search the current codebase for the equivalent (`grep -rn`).
3. Either:
   a. Restore the symbol with a back-compatible alias, or
   b. Rewrite the test against the current API.
4. Run `pytest tests/unit/<file> -q` to confirm green.
5. Add the file to `.github/workflows/ci.yml`'s "Core tests" step.
6. Re-run `tools/triage_tests.py` to refresh `docs/test_triage.md`.

## Why we don't just delete

Deletion loses the test author's intent. The names of these tests
(`test_authority_retry`, `test_collision_analytics`, etc.) document
behaviours the system was meant to verify. Restoring them is cheaper
than rewriting from scratch when the production API is restored or
clarified.
